# devrec
Standalone Rust CLI. All implementation uses AF implementation Tasks; verification is an independent reviewer within that Task, never a separate verification Task. Sol medium implements, Sol high verifies by applying the patch/building/installing privately/running tests, Terra high reviews bugs, Astra medium evaluates. All use codex-personal; local gate only. Follow typed versioned contracts, deterministic rendering, atomic recoverable operations, bounded filesystem access, and precise evidence. Never weaken tests or silently resolve substantive contradictions. No AF runtime dependency in the core. Build in this checkout target/. Models and publication only through explicit integration boundaries.
